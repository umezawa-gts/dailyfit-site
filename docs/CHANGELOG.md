
MX・DKIM・各TXTレコードは変更していません。

### なぜ移行したか

1. **Netlify 無料プランが private リポジトリで複数人のコミットを許可しない**（後述の「1か月の停止」の原因）
2. **Netlify 無料プランは本番デプロイが月20回程度で上限**（300クレジット ÷ 15クレジット/デプロイ）。改修フェーズでは足りない
3. **Netlify のプロジェクトが開発担当者の個人アカウント配下にあった**。属人化の解消

GitHub Pages なら、リポジトリと同じ場所・同じ権限で完結します。

### 移行でハマった点

**ドメインが別のGitHub Pagesサイトに押さえられていた。**

```
The custom domain `dailyfit.jp` is already taken.
```

どこかのアカウントが過去に `dailyfit.jp` をカスタムドメインとして登録したまま放置していたようです。DNSがNetlifyを向いていたので実害なく眠っていました。

GitHub のドメイン所有権確認（`_github-pages-challenge-umezawa-gts` のTXTレコード）を通すことで解決しました。これは**今後このドメインを他人が勝手に使えなくする効果**もあります。

**Netlify が裏でリンクを書き換えていた。**

Netlify の「Pretty URLs」が配信時に `href="fudomae.html"` → `href="/fudomae"` と自動変換していました。ソース上は `.html` のままだったため、GitHub Pages に移すと canonical と食い違う状態になるところでした。移行にあわせてソース側を統一しています（`940de9b`）。

### 移行で失ったもの

`_redirects` による301リダイレクトが効かなくなりました。

| パス | 移行前 | 移行後 |
|---|---|---|
| `/fudomae/index.html` | 301 → `/fudomae` | **404** |
| `/shirokanetakanawa/index.html` | 301 → `/shirokanetakanawa` | **404** |
| `/index.html` | 301 → `/` | 200（canonical で正規化） |

Search Console で確認したところ、**旧URLの表示回数は既に0**だったため、実質的な損失はないと判断しました。

## 2026-10-14 1か月止まっていたデプロイの復旧

### 何が起きていたか

**2026-09-11 から 2026-10-14 まで、本番へのデプロイが1件も成功していませんでした。** 公開されていたのは 2026-08-28 の `9c68256` のままです。

原因はこれでした。

```
Build failed: unrecognized Git contributor.
Your plan allows only one contributor on private repos.
```

**Netlify の無料プランは、private リポジトリに対してコミット作者を1人しか認めません。** 登録されていたのは開発担当者のアカウントだけで、そこに別アカウント（`umezawa-gts`）のコミットが入った瞬間からビルドが全てブロックされていました。

デプロイ履歴が症状と完全に一致していました。

| デプロイ | 結果 |
|---|---|
| 2026-08-28 `9c68256`（開発担当者のコミット） | Published |
| 2026-09-11 以降すべて | **Failed** |

月をまたいでも直らなかったため、クレジット切れではないことが確定しました。

### どう直したか

1. **リポジトリを private → public に変更**（contributor 制限は public リポジトリには適用されない）
2. `.nojekyll` を push（`5864de7`）して webhook を再送 → Netlify がリポジトリの公開状態を再評価してビルド成功

public 化の前に、リポジトリ内に機密情報がないことを確認しています（APIキー・トークン・パスワードの検索で0件）。

## 2026-10-14 title / description の見直し、canonical・OGP の追加（PR #2）

Search Console の実データをもとに、3ページの `<head>` を書き換えました。本文・CSS・JS は変更していません。

| ページ | title |
|---|---|
| `/` | パーソナルジム DAILY FIT｜白金高輪・不動前の完全個室 |
| `/fudomae` | 不動前のパーソナルジム DAILY FIT｜完全個室・無料体験 |
| `/shirokanetakanawa` | 白金高輪のパーソナルジム DAILY FIT｜完全個室・無料体験 |

変更の理由:

- **「無料体験」が検索結果に1文字も出ていなかった。** LP内には「まずは無料体験から」「60分・当日入会の強制なし」という最も強いコピーがあるのに、title にも description にも含まれていなかった
- **「完全個室」を title に昇格。** `ジム 個室`（55表示）、`五反田 個室ジム`（38表示）で実際に拾えていた
- **拾えていない地名を description に追加。** 不動前に五反田、白金高輪に高輪・南麻布・麻布十番
- **canonical が全ページに無く、`/` と `/index.html` が重複URLになっていた**

あわせて OGP（`og:*` / `twitter:card`）を追加しました。`og:image` は横長素材が hero 系しかないため全ページ `hero-1.jpg` を指定しています。**将来的には 1200×630 の専用画像を店舗ごとに用意するのが望ましい状態です。**

## 2026-09-11 旧URLの404を301で解消（PR #1）

2026年8月のURL構造変更（ディレクトリ構成 → ルート直下の `*.html`）で、旧URLが404のまま放置されていました。

| URL（3ヶ月の実績） | クリック | 表示 | 当時の状態 |
|---|---|---|---|
| `/fudomae/index.html` | 91 | 2,156 | **404** |
| `/shirokanetakanawa/index.html` | 61 | 1,723 | **404** |

**オーガニッククリック233件のうち152件（65%）が404になったURL経由**でした。

`_redirects` を追加して301で接続する対応をしましたが、前述のデプロイ停止により**本番反映は2026-10-14まで持ち越し**になりました。その間に Google が旧URLをインデックスから落としたため、評価の引き継ぎはほぼ失われています。

**教訓: URL構造を変えるときは、必ず同時に301を用意してください。** GitHub Pages ではサーバー側の301が打てないため、URL構造の変更自体を避けるのが安全です。
